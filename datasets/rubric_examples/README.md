# Rubric examples (SYNTHETIC)

`user_text_rubric_examples_v0.jsonl` holds invented sentences used only to walk annotators through `docs/USER_TEXT_ANNOTATION_RUBRIC.md`.
The labels are the rubric author's illustration, not independent annotation. They are NOT validation data: never use them to measure
accuracy, tune the rules baseline, or train anything. No real user text is collected or stored here.
